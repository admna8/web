# Остео — учебный атлас костей

Статический сайт на HTML, CSS и JavaScript. Содержит восемь учебных карточек со схематическими SVG-иллюстрациями, поиск на русском и латыни, фильтры и тест из пяти вопросов.

## Запуск

```sh
cd /workspace/web
python3 -m http.server 3000 --bind 0.0.0.0
```

Затем откройте сайт на порту 3000. Установка пакетов и ключи API не нужны. Шрифт Manrope загружается с Google Fonts; без сети используется Arial. Иллюстрации локальные, упрощённые, не предназначены для клинического использования.
